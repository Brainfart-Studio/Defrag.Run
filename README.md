# Defrag.Run()

**Outrun the Corruption.**

A fast-paced glitchcore endless runner. Every second the ground behind you gets deleted. Dash, jump, and stay ahead of the decay tearing the digital world apart.

[![Play on itch.io](https://img.itch.zone/aW1nLzI5NDYzMzk5LnBuZw==/180x143%23c/bCp%2FWF.png)](https://brainfartstudio.itch.io/defragrun)

---

## About

This game was created for [Wannibe Manisha​'s](https://wannibemanisha.itch.io/) '[Do You Wanna Jam 2026](https://itch.io/jam/do-you-wanna-jam-2026)​'. The theme was "Unstable." I made the world itself unstable and falling apart. The level fragments and loses  collisions the moment you leave it behind. New terrain assembles itself just ahead of you.

## Controls

**Keyboard**

| Action | Key |
| --- | --- |
| Move | WASD / Arrow Keys |
| Jump | Space |
| Dash | J / X |
| Pause | Esc |

**Controller**

| Action | Button |
| --- | --- |
| Move | D-Pad / Left Stick |
| Jump | South (A / Cross) |
| Dash | West (X / Square) |
| Pause | Start |
